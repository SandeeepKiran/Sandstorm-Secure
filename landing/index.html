Features

The rules a lost or shared phone needs

Each rule is a documented setting in Google's Android Management API. Sandstorm Secure writes the policy. Android Device Policy enforces it on the phone.

  • Always-on VPN with lockdown

    Keeps your VPN app, such as WireGuard, connected. With lockdown on, the phone sends no traffic while the VPN is down.

    alwaysOnVpnPackage

  • No USB file transfer

    Stops file copy to a computer over a USB cable. The phone still charges.

    usbFileTransferDisabled

  • Approved apps only

    The Play Store shows only the application packages on your allow-list. Nothing else can be installed from it.

    playStoreMode: WHITELIST

  • Screenshot and reset controls

    Blocks screenshots and screen recording. On a fully managed phone, the user cannot factory-reset it from Settings.

    screenCaptureDisabled · factoryResetDisabled

  • Screen lock and remote wipe

    Sets a minimum PIN or password strength. An admin can wipe a lost fully managed phone, or remove only the work profile.

    passwordRequirements · devices.delete

How it works

Three steps from new phone to managed phone

  1. Connect Google

    Create a Google Cloud project and a service-account key. Register your business as an Android enterprise. Sandstorm Secure walks you through it.

  2. Choose the rules

    Start from the locked-down baseline policy or the lighter relaxed one. Turn rules on and off, then upload the policy to Google.

  3. Scan one QR code

    On a factory-fresh phone, scan the enrollment QR code from the setup wizard. Google installs Android Device Policy, which applies the rules.

Transparency

What your admin can and cannot see

A managed phone sends some information to the company that manages it. Here is exactly what Google's Android Management API gives the admin.

The admin can see and do

  • The phone's hardware model, brand and Android version.
  • When the phone last reported in, and if it follows the policy (and which setting it does not follow).
  • The names and versions of installed application packages, when application reports are on.
  • Network details (such as Wi-Fi network name on fully managed phones), battery and memory reports.
  • Remote actions: change the policy, add or remove managed apps, wipe a fully managed phone or delete a work profile.

The admin cannot see

  • SMS text messages, call audio, or chat messages in apps such as WhatsApp or Signal.
  • Photos, videos, documents or other files on the phone.
  • Web history, searches, or passwords typed into websites and apps.
  • Anything on the personal side of a phone that uses a work profile.
  • The live screen, microphone or camera. The API has no screen viewing.

FAQ

Questions

Is Sandstorm Secure a real product?

It is a working portfolio project, not a product for sale. The app really applies policies through Google's Android Management API, and it is tested on an Android emulator. This page and its sign-up form are a demo.

Do my phones need a special app?

No custom app. During enrollment, Google installs its own Android Device Policy app. That app applies the rules on the phone.

Does it work with iPhone?

No. Sandstorm Secure supports Android only. Managing an iPhone needs Apple's own certificates and Apple Business Manager.

Is the dashboard on the internet?

No. The dashboard can wipe phones, so it runs only on your own computer, at 127.0.0.1. Only this page and the sample-data demo are meant to be public.

Can my employer read my messages?

No. The admin cannot read messages, see photos or view your screen. See What your admin can and cannot see for the full list.
