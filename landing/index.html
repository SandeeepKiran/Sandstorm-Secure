Who This Is For

Small teams with 5 to 50 company Android phones and no dedicated IT administrator — such as field service crews, clinics, delivery teams, and agencies that hand out work phones or add managed work profiles to staff devices.

Instead of writing a custom Android agent, Sandstorm Secure uses Google’s built-in Android Device Policy enforcement engine.

What Sandstorm Secure Enforces on Managed Phones

Every policy rule below maps directly to a documented Google Android Management API (AMAPI) setting.

  • Always-On VPN with Lockdown (alwaysOnVpnPackage): Keeps your chosen VPN app (such as WireGuard) connected at all times and blocks network traffic when the tunnel is down.
  • USB Data Transfer Block (usbFileTransferDisabled): Disables MTP/PTP file transfers over USB cables while still allowing normal battery charging.
  • Play Store Application Allow-List (playStoreMode: WHITELIST): Restricts Google Play so users can only install explicitly listed work packages.
  • Screen Capture & Factory Reset Controls (screenCaptureDisabled, factoryResetDisabled): Prevents screenshots/screen recordings and blocks unauthorized factory resets from the Settings app on fully-managed phones.
  • Screen-Lock Rules & Remote Wipe (passwordRequirements, enterprises.devices.delete): Enforces minimum PIN/password complexity and allows an administrator to factory-reset a lost fully-managed phone or remove a work profile remotely.

What an MDM Provider Can and Cannot See

Plain-language disclosure: managing a phone through Google AMAPI gives the enterprise administrator specific device telemetry and remote actions, while personal content inside apps stays private.

What the Administrator CAN See & Do

  • Device hardware model, brand, and Android OS version reported by AMAPI.
  • Last status report timestamp and policy compliance state (plus which setting is out of compliance).
  • Names and version numbers of installed application packages (when applicationReportsEnabled is on).
  • Network metadata (Wi-Fi SSID / MAC address on fully-managed devices) and power/memory status reports.
  • Remote actions: switch policies, push or remove managed apps, and factory-reset a fully-managed device (or delete a work profile).

What the Administrator CANNOT See

  • SMS text messages, call audio, or personal chat messages inside apps (such as WhatsApp or Signal).
  • Photos, videos, documents, or local files stored on the device.
  • Web browsing history, search queries, or passwords typed into websites and apps.
  • Personal-side apps, photos, or accounts when enrolled in Work Profile mode.
  • Live screen viewing or microphone/camera feeds (AMAPI does not provide screen streaming).
